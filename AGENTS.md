# Project Preferences & Asset Generation Rules

- **PNG Asset File Size Requirement**: 
  - Minimum File Size: **2.0 MB** (Every generated PNG asset must be at least 2.0 MB)
  - Maximum File Size: **10.0 MB**
- **Image Specifications**:
  - Resolution: High Resolution / 4K UHD (3840x2160 or 5120x2880) with True 32-bit RGBA Alpha Transparency.
  - Detail Level: Ultra-detailed with micro-textures, organic liquid grain, and rich particle spray to preserve high graphic fidelity and maintain the required 2MB - 10MB uncompressed PNG size range.
