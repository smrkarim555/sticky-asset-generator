# 🚀 Diagonal Volumetric Stage Spotlight Beam & Light Shaft Studio

A high-resolution **3840×3840 (4K UHD)** Diagonal Volumetric Stage Spotlight Beam & Light Shaft Studio app built with React, Vite, Node.js, Express, and Canvas.

---

## 🇧🇩 লোকাল পিসিতে (Local PC) ১-ক্লিকে চালানের নিয়ম (1-Click Run with .bat)

আপনার উইন্ডোজ (Windows) পিসিতে **মাউসের ডাবল ক্লিকেই** পুরো প্রজেক্ট রান করার জন্য ব্যবস্থা করে দেওয়া হয়েছে:

### ১. পূর্বশর্ত (Prerequisites):
আপনার কম্পিউটারে **Node.js** ইনস্টল থাকা লাগবে।
> না থাকলে [nodejs.org](https://nodejs.org/) থেকে ইনস্টল করে নিন।

### ২. যেভাবে চালাবেন (How to run):
1. প্রজেক্ট ফোল্ডারে থাকা **`run.bat`** ফাইলে মাউসে **ডাবল ক্লিক (Double Click)** করুন।
2. প্রথমবার চালানের সময় এটি স্বয়ংক্রিয়ভাবে প্রয়োজনীয় প্যাকেজগুলো ইনস্টল করবে।
3. ৩ সেকেণ্ড পর অটোমেটিক আপনার ব্রাউজারে `http://localhost:3000` লিংকটি ওপেন হয়ে যাবে এবং অ্যাপ চালু হয়ে যাবে!

---

## 🇬🇧 How to Run via `run.bat` on Windows PC

1. Make sure **Node.js** is installed on your Windows PC.
2. Simply **double-click on `run.bat`**.
3. It will automatically install packages (on first run), launch the server, and open `http://localhost:3000` in your browser.

---

## 🎨 Features
- **4K Ultra-Wide Square Resolution**: 3840 x 3840 pixels
- **True Alpha Transparency**: 32-bit RGBA PNG cutouts
- **Guaranteed High Quality File Size**: 2.0 MB - 10.0 MB per asset
- **Interactive Background Test Canvas**: Test against dark studio, transparent checkerboard, white, and parchment background.
- **Lossless 1-Click Downloads**: Direct downloading of full 4K PNG stage spotlight assets.
